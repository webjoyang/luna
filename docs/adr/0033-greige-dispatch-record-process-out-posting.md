# ADR-0033：发染记录挂胚布单，PROCESS_OUT 过账、不足拦截、受限编辑

**状态**：Accepted
**日期**：2026-09-28
**关联**：生产管理-生产进度；ADR-0017（通用库存流水）、ADR-0027（发纱 YARN_OUT/不足拦截/红冲先例）、ADR-0031（进度反馈零回写先例）、ADR-0009（无编号先例）

## 背景

旧系统的"胚布发染厂"由 `FabricPullRecord`（拉胚记录）承载：挂在订单进度（OrderProgress）上、用 productKey 文本复合键关联产品、创建即扣可用量**不写库存流水**。新系统已删除订单实体（合同为唯一锚点），且染色环节的进度反馈（ADR-0031）只覆盖"染色执行"不覆盖"发去染厂"的物流环节——"胚布→染厂"在数据上断链。需要一个新的轻量实体补齐该环节，并回答挂载点、库存口径与编辑边界。

## 决策

### 1. 实体：GreigeDispatchRecord（发染记录）

- 挂**胚布单**（`greigeOrderId` 必填）而非合同——"发染"是胚布单的下游动作；可空指向染色单（`dyeingOrderId`）与承染染厂（供应商 ID+名称快照），均可**后续补填**。补填染色单时校验其合同与胚布单合同**一致**（不一致报错，防进度血缘跨合同错乱）。
- **一张胚布单可多次发染**（多条记录，分批发运是常态），该单已发染量 = 有效记录合计。
- 粒度为**按胚布单整单一条**：一次发运一条记录，产品快照取胚布单品种，颜色不细分（同旧系统产品级粒度）。颜色级血缘（`greigeOrderColorId` ↔ 染色颜色行）后置，等出现按色跟产的刚性需求再加。
- 无业务编号（同染色单 ADR-0009 先例），靠"胚布单+日期"识别；软删除。

### 2. 过账：PROCESS_OUT / PROCESS_OUT_REVERSAL

- 创建即生效，同事务写库存流水 `PROCESS_OUT`（负数，扣胚布库存；`related_doc_type=GREIGE_DISPATCH`，`related_doc_id=记录ID`）。
- 仓库**由弹窗必选**（胚布单无仓库字段，不自动猜），仅可选**启用仓**（停用仓不可被新单选择，同仓库档案守卫）；记录存仓库 ID+名称快照；红冲沿用同一仓库。
- **库存不足拦截**（同领纱发纱 ADR-0027 先例）：同仓同产品 KG 余额小于发染量时报错——不允许账面负库存。坯布"直发染厂"场景须先补入库单再发染；"直发免入库"作为后置扩展，本期不做。

### 3. 受限编辑

- 创建后**仅允许**补填/修改 `dyeingOrderId` 与染厂、修改备注；数量/日期/匹数/仓库锁定。
- 录错 → 删除（写 `PROCESS_OUT_REVERSAL` 正数红冲，关联原流水）→ 重录。不提供"改数量自动红冲+补写新流水"的复杂路径，保流水对账简单。

### 4. 零回写与双入口

- 不回写胚布单、染色单状态（零回写惯例）。
- 双入口：**胚布单列表页行操作"发染记录"→抽屉**（胚布单无工作台，选抽屉而非建工作台）；**染色单工作台另设"发染记录"页签**（同进度反馈页签先例）。两入口复用同一弹窗与同一套接口；染色单侧只读胚布单信息、不回写。

## 后果

- 库存账闭环：发染量有流水可查、删除有红冲留痕，可从流水反查每笔发染。
- 直发场景必须先入库，操作序列变长——换取单一库存口径；直发免入库后置。
- `sentToDyeingKg`（已发染量）可从发染记录表直接聚合（记录→胚布单→合同），不必绕流水 join。
- 错误码使用 `1-030-018` 段。
