# 02: 供应商主档案端到端（建表/编号 → CRUD → 列表页 → 基础档案工作台）

**What to build:** 采购人员可以在系统里完成一家供应商主档案的完整生命周期管理：执行部署脚本后，在"基本信息-供应商信息"菜单看到列表；新建时系统自动分配 `SUP+年份+4位序号` 的编号（也可手填承接历史号），填写公司名称等基础信息后保存；可按关键词、供应商类型、状态筛选查找；可进入工作台查看/编辑基础档案；可停用与删除（删除即先停用再逻辑删除，编号永不重用）。工作台同时出现 6 个 Tab，其中"基础档案"可用，"入库记录/付款记录/关联品种/位置分布"显示"开发中"占位（"联系人"Tab 在 03 号工单激活）。

**Blocked by:** 01 公司名字段统一正名 company→companyName（先行重构）

**Status:** ready-for-human

- [x] 部署 SQL 可重复执行：建供应商主表与主键序列（含全量唯一索引、状态与类型索引、全列注释）、注册供应商菜单与增改删按钮（挂"基本信息"目录）、初始化供应商类型字典 18 项（value 编码与 spec 一致）
- [x] 供应商建档：公司名称必填；编号留空时自动生成当年编号（SUP+年份+4 位、补零、超 9999 扩位）；手填编号按原值保存；简称留空自动用公司名称回填；状态缺省 ACTIVE；类型/机型/电话/地址/备注均可空
- [x] 提供只读"预览下一个编号"：连续调用不占号，期间无新建时返回值不变
- [x] 编号租户内全量唯一：手填或改号与在用编号撞号时报"编号已被占用"（错误码 1-030-005-001）；与**已逻辑删除**供应商撞号同样报错；自动取号撞号时有限次顺延重试
- [x] 取号与查重扫描显式包含已删除行（ADR-0005），代码处有注释标明是刻意绕过逻辑删除过滤
- [x] 分页接口支持搜索词（命中编号/公司名称/简称/电话）+ 供应商类型等值 + 状态等值三个条件可组合，按创建时间倒序
- [x] 详情、修改（改号触发全量查重且排除自身）、单删、批量删除行为正确；删除不存在的供应商报 1-030-005-000；删除时先置 INACTIVE 再逻辑删除
- [x] 7 个端点均挂权限码 lunaerp:baseinfo:supplier:{query|create|update|delete}，无权限访问被拦截
- [x] 前端列表页：搜索词框+类型下拉(18 项字典)+状态下拉；列含编号/公司名称(简称副标题)/类型 DictTag/电话/地址/状态/操作；新建、编辑、删除二次确认、勾选批量删除、分页均可用；按钮受 v-hasPermi 控制
- [x] 前端工作台 6 Tab 框架：基础档案 Tab 可查看并保存全部主表字段（编号可预览/手填、编辑时可改）；4 个占位 Tab 显示"开发中"；联系人 Tab 先显示占位态（03 号工单接管）；支持 URL 直达与列表行"查看/编辑"入口
- [x] 新增供应商 Service 纯 Mockito 单元测试，覆盖自动取号/序号 max+1/补零扩位、手填与软删行撞号、自动号重试、预览不占号、简称回填、状态缺省、不存在错误码、删除先停用后删除、批量删除、分页条件透传
- [x] 多租户与软删除由 TenantBaseDO/框架自动处理；无银行、信用代码、合作状态、经纬度、附件、财务统计、草稿审批等超范围字段
