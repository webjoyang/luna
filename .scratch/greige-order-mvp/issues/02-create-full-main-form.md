# 02: 手工新建胚布单（完整主表路径）

**What to build:** 用户点"新建胚布单"进入整页表单，录入完整主表信息后保存，列表中立即出现新单据。编号自动生成可预览、也可手填；坯布厂必选、染厂可空，均通过远程搜索选择供应商；合同与胚布品种可选手选；输入计划投胚量后匹数自动算出但可手改。

**Blocked by:** 01 胚布单地基：空列表可访问

**Status:** ready-for-human（代码实现与单测完成，运行时验收待人工执行，见 Comments）

- [x] 新建接口与"预览下一个编号"接口可用；编号 PB+月日+3 位流水按天取号，扫描含已删除单据（ADR-0006）
- [x] 手填编号与任意单据（含已删除）撞号时报明确错误、不顺延；自动号并发撞号有限重试
- [x] 坯布厂必填、指定染厂可空；远程选择器不按供应商类型过滤，选项显示"编号+公司名+类型标签"，仅展示 ACTIVE 供应商（ADR-0007）
- [x] 保存坯布厂/染厂的供应商 id 与公司名快照；供应商不存在或不属本租户报引用错误
- [x] 销售合同可空引用（合同 id+编号快照）；胚布品种可空、手工选择不自动识别；引用不存在时报错
- [x] 品种规格字段齐备：产品编号/名称（可远程搜索产品档案回填后再改）、成分、幅宽、克重、缩水率
- [x] 匹重数值化（KG，缺省 25）；计划投胚量填写后按 ceil(投胚量÷匹重) 自动回填匹数，匹数仍可手工修改
- [x] 生产计划字段齐备：成品数量、预设损耗（百分比输入/小数传输）、加工费、单据日期（缺省今天）、交货日期、生产工艺备注、备注、状态
- [x] 保存成功后返回列表并可见新单据
- [x] 测试覆盖：自动取号、手填撞号（含软删）、四类引用校验、默认值（日期/状态/匹重/损耗）
