# 06: 入库明细 + 库位放置两级差异保存

**What to build:** 仓管员在入库工作台编辑入库明细与其库位放置后保存，两级子表差异保存、先父（明细）后子（放置）：改明细行时其放置记录原样保留；删明细行时其下放置一并逻辑删除；保留明细行时放置记录可独立增删改。草稿/已审核/已取消状态守卫、审核过账与红冲逻辑完全不变。

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

- [x] 更新入库单时明细差异保存三分流；其后库位放置按 stockInItemId 差异保存，未变更父行 id 不变、放置关联不悬空
- [x] 删除明细行时其下放置逻辑删除；放置 payload 引用本次被删明细行 id 时报校验错误（防御性）
- [x] 提交跨父 id 报错；明细金额重算、放置齐套软提示口径不变；不强制放置齐套的既有行为保持
- [x] 草稿/已审核/取消的状态守卫、审核过账与红冲、级联删除行为完全不变
- [x] 前端入库工作台：明细表格与放置弹窗改为行 id 身份，加载保留、提交回传
- [x] ServiceImplTest：明细四路径 + 放置级联/防御报错用例 + 过账红冲回归用例
- [ ] 人工回归：改明细后放置仍在、删明细后放置消失他行无损、已审核单只能红冲的规则不被破坏
