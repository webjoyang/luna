# 03: 查看与修改染色单

**What to build:** 用户可从列表行"查看/编辑"进入染色单工作台。草稿态（DRAFT）可编辑全部主表字段并保存；进行中（ACTIVE）、已完成（COMPLETED）、已取消（CANCELLED）态只读，编辑操作被拒并返回状态不允许错误。编辑保存时关联引用（合同/染厂）重新校验并更新快照。

**Blocked by:** 02 新建染色单（主表完整表单）

**Status:** ready-for-agent

- [ ] 详情接口返回主表全部字段（本期不含颜色明细，留 04 票）
- [ ] 更新接口可用：仅 DRAFT 态可更新，非 DRAFT 态更新报 1-030-007-001（状态不允许该操作）
- [ ] 更新不存在的染色单报 1-030-007-000
- [ ] 更新时重新校验合同/染厂引用存在性并刷新快照
- [ ] 前端工作台支持查看模式（只读）与编辑模式切换：DRAFT 态可编辑，其他态全控件 disabled 且隐藏保存按钮
- [ ] 列表行"查看"以只读模式打开工作台，"编辑"以编辑模式打开（仅 DRAFT 单据显示编辑入口）
