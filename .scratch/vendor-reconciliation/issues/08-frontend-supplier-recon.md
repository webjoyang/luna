# 08: 供应商对账前端（列表 + 生成/编辑工作台 + 详情抽屉 + A4 套打）

**What to build:** 财务在 luna-ui"财务 → 供应商对账"看到全部对账单及其确认金额、实时已申请额与状态，按状态出现不同操作；点生成进入工作台：选供应商和区间（缺省上月）取数预览，加工费行展示检验单号/类型/ΣKG/ΣM/卷数并可切换计价基准、填单价（产品档案加工费作参考预填），采购货款行展示入库单号/批次缸号/数量/单价（可改），可加正负调整项（必填备注），合计实时汇总；保存、重取（提示调整行会保留）、确认（二次弹窗）。确认后整单只读，可一键打印 A4 对账单给供应商盖章；详情里每行来源单据可点击跳转。
