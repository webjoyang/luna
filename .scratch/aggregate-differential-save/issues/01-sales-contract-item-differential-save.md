# 01: 销售合同明细差异保存

**What to build:** 业务员编辑销售合同（改一行数量、新增一行、删除一行、调整顺序）后保存，合同明细不再"先删后插"：未改动的行保持原数据库行（id、创建人、创建时间不变），改动行走更新，新增行走插入，移除行走逻辑删除。合同总数量/总金额仍由服务端按最新明细权威重算，删除合同仍级联删除明细。合同编辑页加载明细后每行持有并回传后端 id。

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

- [x] 合同明细保存 VO 支持可空行 id；更新合同时对明细做差异保存：带 id 且属于本合同的行走 update、无 id 行走 insert、本合同库内有但本次未提交的行走逻辑删除
- [x] 提交的行 id 不属于本合同时报错（防跨父 id 串数据）；行号按提交顺序重排
- [x] 主表 totalQuantity/totalAmount 等汇总按差异保存后的最新明细重算，结果与改造前一致
- [x] 删除合同仍级联逻辑删除全部明细；零明细合同保存行为不变
- [x] 前端合同编辑页：明细表格以行 id 为稳定 key，详情加载后保留 id，提交时未删行原样回传 id、新增行 id 留空；页面布局与交互无变化
- [x] ServiceImplTest 覆盖四条更新路径：全部原样提交（零删除零新增）、改行 update、删行逻辑删除、加行 insert；断言最终行 id 集与汇总值，不绑定内部实现
- [ ] 人工回归：加载→改行→加行→删行→调序→保存→重开，行不串、数据不丢
