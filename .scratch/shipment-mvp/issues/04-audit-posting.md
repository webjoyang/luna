# 04: 审核出库过账与红冲（三态状态机 + 库存硬校验 + SHIPMENT_OUT 流水）

**What to build:** 发货单具备完整出库闭环。草稿态点"审核"（需 `:audit` 权限）→ 先按"产品 + 单位 + 仓库"把本单明细合并成需求量，与库存余额（流水实时 SUM）比较，任一组合需求量大于可用余额则硬拦截报错（返回需求量与可用量，...016_005）；校验通过后单据转 COMPLETED，同事务按明细行逐条写负数 SHIPMENT_OUT 流水（数量/金额为负，携带产品快照、仓库、缸号、单位、关联凭证，库位为空），卷清单不展开。已发货单点"取消"（`:audit`）→ 同事务按 `(related_doc_type='SHIPMENT', related_doc_id=本单)` 反查原流水逐条写正数 SHIPMENT_OUT_REVERSAL，原流水永不物理删除，单据转 CANCELLED 终态；二次确认，已签收单额外提示。草稿态点"取消"（`:update`）仅作废、不写流水。零明细审核报 ...016_004；非草稿编辑/删除、终态再操作报 ...016_002。前端按状态+权限渲染按钮。

**Blocked by:** 02 (发货单草稿 CRUD)
