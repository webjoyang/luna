# 01: 发染记录后端——过账、红冲、不足拦截

**What to build:** 跟单员/仓库通过 API 对胚布单登记发染记录的完整后端闭环：创建即生效并同事务写 PROCESS_OUT 库存流水（弹窗必选启用仓，记录存仓库快照；同仓同产品余额不足时拦截并返回需求量/可用量）；删除写 PROCESS_OUT_REVERSAL 红冲关联原流水；受限编辑仅允许补填/修改染色单与染厂、改备注（补填染色单校验与胚布单同合同），数量/日期/匹数/仓库锁定；一张胚布单可多条记录；分页查询按胚布单/染色单双向过滤。零回写胚布单与染色单状态。含建表 SQL（production 子包）、库存流水交易类型枚举扩展（PROCESS_OUT / PROCESS_OUT_REVERSAL）、错误码 1-030-018 段、Service 层单测。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**参考**：本目录上级 spec.md；ADR-0033（发染记录）、ADR-0017（流水）、ADR-0027（不足拦截先例）

- [ ] 创建发染记录成功后库存余额按仓库+产品正确减少，流水含 related_doc_type=GREIGE_DISPATCH 与合同信息
- [ ] 余额不足创建被拦截，错误信息含需求量与可用量

- [ ] 仓库仅可选启用仓；创建胚布单不存在/已取消时报错（1-030-018 段）
