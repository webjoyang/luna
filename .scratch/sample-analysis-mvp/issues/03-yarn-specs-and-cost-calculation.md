# 03: 纱线规格明细 + 成本核算闭环

**What to build:**
让分析员能逐行登记布样的用纱结构（全部来自纱线档案），并让系统按确定口径自动算出内部成本。

用户视角的完整行为（针织工艺页签）：

- 新增"纱线规格明细"可增删子表：先选材质、再选该材质下的纱线规格（复用纱线档案现有材质→规格级联查询，支持关键字检索）；选中后系统自动带出纺法与档案参考单价。
- 带出的单价可手工修改（纱价随行就市）；每行再填用纱比例（百分比数字，如 30 表示 30%，必须 >0，否则前端拦截）与备注；不允许手打一条档案里没有的纱线（规格必选）。
- 各行比例合计不等于 100% 时，页面显示"不足/超标"文字提示，但不阻止保存。
- 明细行随主表一起保存（聚合差异保存：增/改/删行正确落库），重开工作台按保存顺序完整还原；纱线档案事后被停用/删除，历史行的材质名/规格名/纺法快照仍可读。
- 同步 seed 纺法字典 lunaerp_sample_spin_method（2254：环锭纺/赛络纺/紧密纺/紧密赛络纺/气流纺/涡流纺，value 与 label 同为中文）；档案快照值不在字典内也照常展示，不报错。

用户视角的完整行为（成本报价页签首建）：

- 可填生产工费、染整费、其他费用、损耗率（百分比数字，5=5%）；编辑态实时预览总成本，保存成功后以服务端返回值覆盖展示。
- 服务端权威计算：纱线成本 = Σ（明细单价 × 比例 ÷ 100），明细单价 >1000 时自动 ÷1000（防吨价误填）；总成本 =（纱线成本 + 生产工费 + 染整费 + 其他费用）÷（1 − 损耗率 ÷ 100），四舍五入两位小数；费用留空按 0。
- 其他费用必须计入总成本；损耗率必须 0≤x<100，填 100、负数或非法值时保存被拒绝并提示损耗率非法（不做静默兜底算法）。
