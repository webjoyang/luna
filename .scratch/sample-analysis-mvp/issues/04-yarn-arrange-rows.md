# 04: 纱线排列绕纱行闭环

**What to build:**
让分析员能在针织工艺页签逐行登记大圆机各路的绕纱工艺描述。

用户视角的完整行为：

- 针织工艺页签新增"纱线排列绕纱"可增删子表，每行四个可空自由文本：路号、绕纱表述（如"25.1cm/1 花宽"）、对针（如"第一路对针"）、描述（如"开幅线"）。
- 行可任意新增、删除（删行无需确认或仅轻确认，与纱线明细行交互一致），全部留空也允许保存；行按保存顺序展示，无手工行号字段。
- 随主表聚合保存（差异保存），重新打开完整还原；主表删除时绕纱行级联逻辑删除。

**Blocked by:** 01（行走骨架——样品分析来样登记闭环）

**Status:** ready-for-agent

- [ ] 可新增任意数量绕纱行并填写四个文本字段；四字段全空的行也能保存
- [ ] 更新时新增/修改/删除行差异正确落库；重开顺序与内容一致
- [ ] 删除主表后绕纱行全部逻辑删除、不可经详情再查出
- [ ] 后端 Service 单测覆盖绕纱行聚合差异保存（增/改/删差集）与级联软删
- [ ] 列名不使用 SQL 保留词 desc（描述列命名为 description）
