# 05: 发货明细 + 卷清单两级差异保存

**What to build:** 业务员/仓管员在发货工作台编辑明细与其卷清单后保存，两级子表都改为差异保存且严格"先父行（明细）后子行（卷）"：修改明细行时该行 update、其下卷记录原样保留（卷 id 不悬空）；删除明细行时其下卷清单一并逻辑删除，其他行不受影响；保留明细行前提下增删改卷记录各自三分流。仅草稿态可编辑的守卫不变。

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

- [x] 更新发货单时发货明细差异保存三分流；其后卷清单按 shipmentItemId 差异保存，未变更父行 id 不变从而卷关联不悬空
- [x] 删除某明细行时其下卷记录随之逻辑删除；卷 payload 引用了本次被删明细行 id 时 service 层校验报错（防御性，正常前端不可达）
- [x] 提交行 id 不属于本单/卷 id 不属于本单时报错；行号/汇总（货物金额、总匹数）按差异保存后结果重算一致
- [x] 仅草稿可编辑/删除、审核过账与红冲逻辑完全不变；删除发货单仍级联逻辑删除明细与卷
- [x] 前端发货工作台：明细表格与卷清单弹窗均改为行 id 身份（当前以数组下标维护），加载保留、提交回传
- [x] ServiceImplTest：明细四路径 + 卷清单"父行保留时独立增删改/父行删除时级联/引用被删父行报错"用例；过账红冲回归用例
- [ ] 人工回归：改明细数量后卷记录仍在、删明细后卷消失他行无损、卷清单总览数据正确
