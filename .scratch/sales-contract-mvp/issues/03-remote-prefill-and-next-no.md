# 03: 建档联动增强（产品库回填、客户带出联系人/地址、取号预览）

**What to build:** 录合同的三处远程联动到位，减少重复录入：① 明细行输入产品编号时远程搜索产品库，选中后自动回填品名/成分/门幅/克重/单价；② 表单选中客户后自动带出联系人与地址；③ 编号输入框旁"获取编号"按钮可实时预览下一个自动编号。所有回填值仍允许手工修改，产品编号也允许直接手填产品库之外的值。

**Blocked by:** 01: 销售合同骨架端到端（主表 CRUD 跑通）；02: 商品明细聚合端到端（子表 + 服务端重算 + 级联删除）

**Status:** ready-for-agent

- [ ] 后端新增 `GET /admin-api/lunaerp/business/sales-contract/get-next-no`：复用 01/02 的取号入口返回当前租户当年下一个合同编号字符串；挂 query 权限 `lunaerp:business:sales-contract:query`；只读、不占号（多次调用在无新建时返回相同值）
- [ ] 前端编号输入框旁增加"获取编号"按钮，点击调用 get-next-no 回填合同编号输入框；用户已手工输入时不自动覆盖（或仅在输入为空/占位时回填）
- [ ] 前端客户远程选择增强：选中客户后调用客户详情，自动回填 clientContact（取主联系人姓名，可空则留空）与 clientAddress，两字段仍可手工修改；快照 clientName 仍按 01 票保存
- [ ] 前端明细行产品编号改为远程搜索 el-select：调用现有产品分页/查询接口按编号或品名模糊搜索；下拉显示编号+品名；选中后回填 productName/composition/width/weight/unitPrice（字段名以产品库实际模型为准，缺失字段留空不报错）
- [ ] 回填后所有明细字段保持可编辑；允许不选择下拉项直接手填任意 product_code（定制品种），手填不触发回填、不做存在性校验
- [ ] 单元测试补一例：get-next-no 的 Service 行为与自动取号一致（当年无合同时返回 CH{year}0001；已有最大号时 +1；含已删除行占用的序号）
- [ ] 验收：新建合同点"获取编号"显示预期下一号，连点两次值不变且用该号保存成功后再次获取已顺延；选择客户后联系人/地址自动出现并可改、保存后以修改值落库；明细行远程搜产品选中后五个字段自动回填，改单价后行金额与汇总照常重算；手填一个产品库不存在的编号也能保存；编辑老合同回显不受远程回填影响（以已存快照为准，不被产品库当前值覆盖）
