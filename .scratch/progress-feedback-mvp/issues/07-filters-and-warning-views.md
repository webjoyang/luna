# 07: 缸卡墙筛选增强与预警视图

**What to build:** 在 02 票基础筛选之上，补齐跟单员的预警与定位视图：一键"仅看延期"（过染色单交期未完成的缸）、"仅看未决问题"（存在未闭环反馈记录的缸）、"含已完成"开关（默认隐藏全缸完成的颜色行）、"含已失效"开关（染色单软删后的残留缸默认隐藏）、颜色名称/客户色号/缸号关键词搜索；点击统计条计数联动筛选；物料单元快速定位条（按染色单/合同+产品聚合）与筛选双向同步并滚动定位到颜色行节。延期缸卡红色标记完整呈现。

**Blocked by:** 02（覆盖层只读缸卡墙骨架——基础筛选与统计条）、05（反馈记录流水——未决问题筛选依赖问题数据）

**Status:** ready-for-agent

- [ ] 仅看延期：缸级筛选，延期口径（染色单交货日期 < 今天 且非 COMPLETED）与卡片红色标记一致
- [ ] 仅看未决问题：筛出含未闭环反馈记录的缸/颜色行节
- [ ] 含已完成开关：默认进行中视图（全缸 COMPLETED 的节隐藏），开启后显示；含已失效开关：染色单软删的缸默认隐藏、开启可查
- [ ] 关键词搜索匹配颜色名称、客户色号、缸号
- [ ] 统计条各计数可点击，点击即应用对应筛选并保持计数口径一致；再次点击可取消
- [ ] 物料单元定位条：按染色单/合同+产品聚合的快捷入口，点击与筛选条件双向同步、滚动定位目标节
- [ ] 全部增强筛选下推骨架查询，分页/节内容/统计条三者口径一致
- [ ] 人工回归：造延期缸、未闭环问题缸、已完成节、软删单残留缸四类数据，逐一验证筛选组合与统计联动
