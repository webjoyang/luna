# 01: 行走骨架——样品分析来样登记闭环

**What to build:**
让业务员能在新系统中完成样品分析最核心的"登记—查看—编辑—删除"闭环，并为后续六张票铺好全部地基。

用户视角的完整行为：

- 主导航出现"样品管理"顶级菜单及其下"样品分析"入口；无查看权限的角色看不到菜单、直访 URL 被拒。
- 进入列表：分页表格（每页 10 条），列含样品编号、客户、产品名称、客户款号、门幅、克重、登记人、登记日期（照片缩略图列、付款标签列先留空位，后续票补）；一个关键字框模糊搜索样品编号/客户名/产品名/客户款号/成分。
- 点"新建"进入空白工作台：可下拉搜索选择客户档案（保存客户 ID + 名称快照），也可不选客户直接手填客户名称；联系人、客户款号自由文本；产品名称必填，成分、门幅（CM）、克重（GSM）自由填；三个工艺分类（工序/双染工艺/机型）字典下拉可空；实测产量与 11 个机台参数（花号、白胚门幅、白胚克重、花宽、花高、齿轮、布架、开机转数、送纱盘、理论产量、线长）可空自由文本；备注可填。
- 保存时服务端生成样品编号 `SA+公历年+4位流水`（可在新建前只读预览、预览不占号），也允许手填；编号租户内全量唯一（含软删行），撞号明确报错；流水跨年从 1 起、超 9999 自然扩位。
- 保存时服务端自动按 `100000/(门幅×克重)` 计算米长并只读展示；门幅/克重缺失或为非正数时米长为空显示"-"。
- 列表点行进入只读工作台，可切编辑态修改后保存；登记人（当前用户姓名）仅创建时写入快照，后续编辑不变。
- 删除为逻辑删除（前端二次确认），编号不释放、不重用。

本票同时把地基一次铺齐（后续票直接长在上面）：

- 样品管理域后端包结构（controller/service/dal 下 `sample.sampleanalysis`）与前端临时实现区 `sample/sample-analysis` 目录、API 封装、菜单驱动路由。
- 主表 DDL 一次建全：来样与机台字段之外，成本/报价/月结收费标量列（生产工费、染整费、其他费用、损耗率、总成本、对外报价、报价备注、is_paid、unit_price 缺省 30、登记人快照列）与两个 JSONB 列（photos、stitch_arrange）本次都建好但不开放界面；三个聚合子表（纱线规格明细/绕纱行/供应商报价）由后续票各自在同一可重复执行 SQL 中追加 CREATE TABLE。
- 三个工艺字典 seed：lunaerp_sample_process（2251）、lunaerp_sample_dyeing_process（2252，13 项）、lunaerp_sample_machine_type（2253）；菜单 10600 样品管理（sort 104）、10610 样品分析及 10611 创建/10612 修改/10613 删除/10614 收费四个按钮位（收费按钮位先建好，行为在票 02）。
- 错误码常量类建好（段 1-030-018：000 不存在、001 编号重复、002 关联引用不存在、003 损耗率非法、100 纱线规格不存在），本票先使用 000/001/002（客户分支）。
- 列表/详情/预览编号/创建/更新/删除端点可用；工作台为只读/编辑两态、三个页签（来样信息/针织工艺/成本报价）的壳先搭好，后两个页签本票只放机台参数字段区与"功能待后续上线"的空区块。
