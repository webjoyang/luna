# 05: 三角排列画板闭环

**What to build:**
让分析员能在针织工艺页签用网格画出大圆机针盘三角排列，并随样品持久化还原。

用户视角的完整行为：

- 针织工艺页签出现三角排列画板：默认 4 行 × 24 列按钮网格；每点击一个格子，符号按 空 → v（成圈）→ -（集圈）→ +（浮线）→ =（其它）→ 空 循环。
- 提供"+4 列""-4 列"按钮调整列数（列数不低于一个合理下限，如减到 0 列时禁用减号），以及"清空"按钮（清空全部格子回到全空，二次确认）。
- 画板内容随主表保存到 stitch_arrange JSONB，重新打开工作台时行列数与每格符号完整还原。
- 画板是纯工艺记录，不参与任何成本或统计计算。

服务端契约：载荷形状为 `{ columns: number, rows: 4, data: string[][] }`，符号只允许空串/v/-/+/=；形状或符号非法时保存被拒绝。

**Blocked by:** 01（行走骨架——样品分析来样登记闭环）

**Status:** ready-for-agent

- [ ] 初始画板为 4×24 全空；点击格子按五态顺序循环，第六击回到空
- [ ] +4/-4 按 4 列步进扩缩并保留已有格子内容；列数为下限时减号禁用；清空需二次确认且生效
- [ ] 编辑若干格并调整列数后保存，重开还原完全一致（行列数、每个符号）
- [ ] 非法载荷（rows≠4、data 维数不符、出现五态以外符号）经 API 保存时被拒绝并返回校验错误
- [ ] 画板取值不影响米长、总成本、收费统计任何数值
- [ ] 后端 Service 单测覆盖：合法透传保存/还原、三类非法形状报错
- [ ] 前端以 Element Plus 按钮网格实现（非 canvas 手绘），不引入额外图形依赖
