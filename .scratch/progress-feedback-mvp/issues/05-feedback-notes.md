# 05: 反馈记录流水（独立子资源：时间线 + 问题闭环）

**What to build:** 跟单员在缸卡点"反馈"快速记一条沟通记录（文字必填、可勾选"这是问题"），记录立即进入缸详情的时间线（时间、记录人、内容、问题标记、闭环状态，系统自动写人与时间）；问题记录可点"闭环"并记录闭环时间，缸卡上未闭环问题以红点计数提示，全部闭环后红点消失。记录只增不改；普通记录可删，已闭环问题不可删、不可重复闭环。

**Blocked by:** 04（状态推进与缸详情编辑）

- [ ] 新增：content 必填、issueFlag 可勾选；记录人与记录时间由系统写入；支持从缸卡快捷反馈弹窗与缸详情两处入口
- [ ] 时间线在缸详情抽屉内展示，排序一致；问题记录显示待闭环/已闭环（含闭环时间）
