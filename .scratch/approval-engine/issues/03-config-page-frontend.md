# 03: 审批链配置页（前端）

**What to build:** 管理员在「审批中心 → 审批链配置」页可查看流程列表、新建/编辑审批流程，为每个流程添加多个节点并指定节点顺序、节点类型（逐级/或签/会签）、节点名称、审批人来源（指定用户多选/指定岗位/指定角色/部门负责人/提交人直属上级）；可启用/停用流程、删除未引用的流程。

**Blocked by:** 02 (审批链配置 CRUD 后端)

**Status:** ready-for-human

- [x] 审批链配置列表页：展示流程名称、单据类型（字典）、状态、操作（编辑/启用停用/删除），按单据类型筛选
- [x] 新建/编辑表单：流程名称、单据类型下拉、备注；节点列表编辑器
- [x] 节点编辑器：节点名称、顺序（自动编号可调整）、节点类型单选（逐级/或签/会签）、审批人来源下拉，来源为 USER 时弹出用户多选、为 POST/ROLE 时选岗位/角色、DEPT_LEADER/SUBMITTER_LEADER 无需额外选择
- [x] 启用/停用切换：调用 status 接口，停用后才能启用同 biz_type 新流程
- [x] 删除确认：调用删除接口，后端拒绝时提示「流程已被引用，无法删除」
- [x] 字典标签使用 `DictTag` 组件渲染单据类型/节点类型/状态
- [x] 页面权限受 `lunaerp:approval:config:*` 控制，无权限按钮不显示
