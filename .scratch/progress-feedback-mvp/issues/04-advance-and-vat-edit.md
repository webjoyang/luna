# 04: 状态推进与缸详情编辑（六工序时间轴）

**What to build:** 跟单员在缸卡点"推进"，缸逐格前进（已排缸→染色中→固色中→质检中→已完成），后端自动在新阶段盖当天日期戳；点缸卡打开详情抽屉，看到六工序时间轴（排缸日/染色开始/固色开始/质检日/完成日，未到达为空态、当前工序高亮），并能编辑缸信息（缸号、数量、匹数、延期原因、备注）、人工修正各阶段日期、经二次确认后把状态回退到上一工序。

**Blocked by:** 03（建缸闭环）

**Status:** ready-for-agent

- [ ] 推进接口：严格顺序逐格，不允许跳格；写入目标状态并把对应阶段日期戳盖为当天；COMPLETED 无后继、推进入口消失
- [ ] 缸详情接口：缸字段 + 五阶段日期 + 颜色行/染色单实时信息（交期、染厂等）+ 延期标记/覆盖率
- [ ] 编辑接口：缸号（仍受同单同色唯一校验）、数量、匹数、延期原因、备注、五个阶段日期可修正；状态可回退一格（前端二次确认；回退不强制清日期，日期以人工修正为准）
- [ ] COMPLETED 缸仍可修正日期与备注（内部跟单记录非过账凭证，不设严格终态锁）
- [ ] 推进权限 advance（10403）与编辑权限 update（10402）分离；时间轴用 el-steps/el-progress 呈现
- [ ] ServiceImplTest：每格推进成功且对应日期戳写入、跳格被拒、COMPLETED 再推进被拒、日期修正生效、回退放行（二次确认在前端）、改缸号撞重 001
- [ ] 人工回归：连续推进五格日期自动正确、回退确认文案、录错日期可改、刷新后持久
