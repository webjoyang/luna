# ADR-0017：通用库存流水台账 + 实时聚合余额（含仓库/库位属性）

**状态**：Accepted
**日期**：2026-09-23
**关联**：库存管理-入库管理 MVP；本 ADR **取代（supersedes）** ADR-0012（已于 2026-09-21 deprecated 回退）

## 背景

ADR-0012 曾为纱线采购设计专用流水台账 `lunaerp_production_stock_ledger`（关联 yarn_spec_id、采购单 ACTIVE→COMPLETED 自动写 STOCK_IN、无库位），该设计已于 2026-09-21 因"功能设计不完善、过早开发"整体回退，前后端程序与表全部取消。

本次入库 MVP 需要承接库存数据落点：ADR-0013 检验同步入库延后的前置条件正是"入库单模块就绪"。问题是：库存账按什么形态建？

## 决策

建**产品通用维度**的流水台账 `lunaerp_stock_ledger`，只存流水、不存余额表：

1. **通用维度**：以 `product_id`（产品档案）为核心，而非纱线规格专用；任何来源（采购/生产/退货/其他入库）的货物共用一张台账。
2. **流水属性**：产品快照、仓库（必填）、库位（可空）、批次（自由文本）、收支类型（STOCK_IN 正 / STOCK_IN_REVERSAL 负）、带符号数量与金额、单位（KG/M）、关联单据（类型+ID+单号快照）。
3. **显式审核驱动**：流水只由入库单审核（正数）与红冲取消（负数）在同一事务写入；草稿不产生流水。不做"采购单完成自动入库"之类的隐式触发。
4. **过账展开**：按库位放置记录展开——每条 placement 一条流水；未分配库位的明细按行写一条 location 为空的流水。红冲按 `(related_doc_type, related_doc_id)` 反查原流水逐条取反。
5. **实时聚合余额**：不建余额表，余额 = `SUM(quantity) GROUP BY product_id, unit, warehouse_id`；本期提供只读余额查询与流水分页两个接口。
6. txn_type 为后端内部枚举，不入系统字典（同 ADR-0012 先例）。

## 理由

1. **流水而非余额表**：保留完整审计轨迹，每一笔库存变化都能追到入库单与库位；未来出库/盘点/调拨只需追加 txn_type 枚举与写入口，余额口径不变。余额表无法回答"这批货从哪来、谁操作的"。
2. **通用产品维度而非纱线专用**：ADR-0012 回退的核心教训之一是台账绑死在纱线规格与采购单上；入库类型有采购/生产/退货多种，货物是胚布/成品/纱线等任意产品，台账必须先通用、后扩展。
3. **显式审核而非自动触发**：自动触发（采购单完成即入库）剥夺了仓管"实物到货才入账"的确认环节，且状态联动一旦回退会造成假库存。审核动作使单据状态与实物验收对齐，也让 ADR-0016 状态机有明确账目语义。
4. **库位可空**：允许"先入账后上架"的部分放置场景，余额口径不被空库位打碎（余额聚合维度不含 location）；库位存量本期仅在单据放置记录中可见。
5. **聚合维度带仓库不带库位**：同一产品在不同仓库的库存不可混用；库位级收发存报表依赖移库/出库模块，本期不做四维聚合避免半成品口径。
6. **不做负库存校验**：本期无出库模块，除红外冲外余额只增不减；校验待出库模块上线时与"占用/冻结"概念一起设计。

## 考虑过的备选

- **库存余额表（直接存余量）**：查询最简单。但无审计能力，出库/盘点上线即需重构，且要解决并发更新与一致性。否决。
- **复用/复活 ADR-0012 纱线专用台账**：维度不匹配（yarn_spec_id 无法表达胚布/成品入库），且自动触发模式已被回退否决。否决（本 ADR 正式取代之）。
- **入库单表直接 SUM 出余额（不建台账）**：已取消单与红冲口径会污染聚合，也无法承接未来出库/盘点流水；单据表不是账。否决。
- **流水强制带库位（审核必须 100% 分配）**：账实位置最严谨，但挡住"货到未上架"的正常业务节奏。MVP 允许库位为空。否决。
- **按产品+单位+仓库+库位四维聚合余额**：需要处理未分配库存与移库，超 MVP 范围。否决。

## 后果

- `lunaerp_stock_ledger` 数据只增不改不删；红冲追加反向行，SUM 自动回平。
- 余额查询为聚合 SQL（必要时 Mapper XML），数据量大时可加物化汇总表，但本期不建。
- 未来出库单审核写 STOCK_OUT 负数、调拨写一负一正、盘点写盘盈/盘亏，均追加枚举与写入口即可；届时需要补负库存校验与按库位维度的台账扩展（加列 location 已就位，余额维度再放开）。
- 检验单同步入库（ADR-0013）落地时，其产物是 DRAFT 或直接过账的入库单，流水仍只由本 ADR 的审核路径产生，同步逻辑不得直接写台账。
