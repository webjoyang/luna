# 07: 打印发货单与装箱清单（浏览器打印，:print 权限）

**What to build:** 对已发货（COMPLETED）发货单，业务员可点"打印发货单"输出随货同行单据（客户、发货/收货地址、承运商、运单号、按明细行汇总的品种/色号/缸号/数量/匹数/金额、合计、日期），仓管可点"打印装箱清单"按卷输出（卷号、所属产品/缸号、每卷重量/米数）。两种版式均为前端打印样式 + window.print，不依赖服务端 PDF。打印操作受 `lunaerp:business:shipment:print` 权限控制（10125），无权限按钮不显示。

**Blocked by:** 03 (卷清单)、04 (审核出库过账与红冲)

**Status:** done
