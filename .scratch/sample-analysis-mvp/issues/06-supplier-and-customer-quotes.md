# 06: 供应商报价登记 + 对外报价闭环

**What to build:**
让分析员在成本报价页签登记供应商的胚布报价参考，并记录给客户的对外报价；两类报价都是纯登记，绝不污染内部成本与收费口径。

用户视角的完整行为：

- 成本报价页签新增"供应商报价"可增删子表：每行通过下拉搜索联想供应商档案，选中保存供应商 ID + 名称快照；也允许不选档案、直接手填供应商名称；可填胚布报价（元/KG，数值可空）与备注。
- 供应商事后被停用或删除，历史报价行仍正常展示、保存、编辑，不受任何"必须有效供应商"拦截。
- 供应商报价行不参与总成本计算（无论填多少胚布报价，总成本只由票 03 的纱线+工费+染费+其他+损耗决定）。
- 成本报价页签可登记对外报价（元/米）与报价备注（如"含税开票不含运费"）；对外报价不参与总成本，也不参与票 02 的未付/已付金额统计。
- 两类报价随主表聚合保存，重开还原；主表删除时供应商报价行级联逻辑删除。

**Blocked by:** 03（纱线规格明细 + 成本核算闭环——共用成本报价页签与主表保存链路）

**Status:** ready-for-agent

- [ ] 报价行可选供应商（ID+快照）或纯手填名称；supplierId 非空但档案不存在时返回 002；停用/已删除供应商的历史行保存与展示均不报错
- [ ] 胚布报价留空可保存；增删改行随主表差异保存、重开还原、删单级联软删
- [ ] 回归验证：任意胚布报价数值下总成本与票 03 口径完全一致；对外报价任意取值不影响总成本
- [ ] 对外报价与备注可保存可改；票 02 三张统计卡金额在任意对外报价下保持不变
- [ ] 后端 Service 单测覆盖：供应商存在性校验（不存在报 002、停用不拦）、纯手填放行、聚合差异保存、"两类报价均不进总成本"回归断言
