# 04: 颜色投胚分配

**What to build:** 用户在胚布单表单中按颜色逐行维护成品下单量与损耗，系统实时并在保存时由服务端权威折算投胚需求；颜色行随单据整体保存、级联删除。零颜色合法，计划投胚量与颜色合计不强一致。

**Blocked by:** 03 查看与修改胚布单

**Status:** ready-for-agent

- [ ] 颜色投胚分配子表已建（含主键序列、order_id 索引）
- [ ] 保存载荷内嵌颜色行，无独立端点；事务内按单删旧行、插新行并重排 line_no
- [ ] 每行字段：颜色、成品下单量(KG)、损耗率、投胚需求(KG)、备注
- [ ] 行损耗为空时取主单预设损耗、再缺省 0；投胚需求按"成品量÷(1−损耗率)"服务端权威重算，前端传值被覆盖
- [ ] 编辑页可编辑颜色表格：新增/删除行、投胚需求只读实时计算、底部展示合计仅供参考
- [ ] 计划投胚量独立保存，不与颜色投胚需求合计做一致校验
- [ ] 查看模式下颜色行只读；零颜色单据可正常保存
- [ ] 详情接口嵌套返回颜色行（按 line_no 排序），列表不返回
- [ ] 测试覆盖：聚合保存（删旧插新/重排行号）、投胚需求重算口径、行损耗缺省取主单、null 成品量按 0
