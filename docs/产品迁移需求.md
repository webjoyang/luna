
现在想要将oldweb（前端）/ oldserver（后端）项目的“基础信息-产品信息”模块完整迁移至目标项目的目标技术栈：
- 前端由 React 项目oldweb迁移到 Vue 3 项目luna-ui;
- 前端将 React 组件、状态管理、路由等重构为 Vue 3 的对应实现;
- 前端的使用体验要与原 React 项目尽量保持一致，包括页面布局、交互逻辑、响应式设计等;
- 前端原 React 项目如果使用了组件库（如 Ant Design、Element Plus 等），则需要在 Vue 3 中引入对应的组件库;
- 后端由 Node.js + Express 项目oldserver迁移到基于 Java SpringBoot 3.x 的芋道（Yudao）模板项目luna-srv中，根据原后端的业务领域模型进行产品信息模块的业务建模;
- 后端将 Express 的路由、中间件、业务逻辑及接口定义转换为 SpringBoot 3.x 的 Controller、Service、Mapper 等分层结构;
- 根据原后端逻辑完成数据库表结构设计与建表语句；
- 生成芋道模板所需的菜单数据（含菜单层级、权限标识、路由路径及组件路径）;
- 确保迁移后功能一致、接口兼容，并适配芋道项目的代码规范与目录结构;

- “产品信息“只是模块lunaerp中”基本信息”中的一个菜单模块，只是lunaerp不在菜单中显示，但是在程序设计中，要将它独立出来，以区分芋道源码原有的模块，
- 后端luna-srv，新建 Maven 模块 lunasrv-module-lunaerp，业务包根 `com.luna.lunasrv.module.lunaerp`，product置于 `baseinfo.product`，接口路径等其他路径按照这个逻辑一起修改，
- 前端的api和view的文件路径都放到lunaerp下，程序路由也是lunaerp下的路由，只是菜单显示上，不要lunaerp这一层，产品信息路由在/lunaerp/baseinfo/product下，权限标识为lunaerp.baseinfo.product
