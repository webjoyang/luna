# 02: 覆盖层只读缸卡墙骨架（颜色行节 + 统计条 + 基础筛选）

**What to build:** 跟单员打开"生产管理 → 进度反馈"菜单，看到以染色颜色明细行为骨架的缸卡墙只读版：每个颜色行一节（合同号、客户、染厂、产品、客户色号/颜色名称、行染色数量/匹数/单位实时取自染色单与颜色行，零快照），节内以卡片网格挂载该颜色行下的反馈缸（缸号、数量/匹数、状态标签、工序进度）；零缸颜色行显示虚线"＋建缸"占位卡（本票仅展示，建缸在 03）。节头显示已建缸合计与排产覆盖率。顶部统计条与基础筛选可用，骨架按颜色行分页。

**Blocked by:** 01（进度反馈 SQL 基建）

**Status:** resolved

- [x] 覆盖层分页查询：以染色颜色明细行为骨架，join 染色单主表，仅聚合 ACTIVE/COMPLETED 单（DRAFT/CANCELLED 排除）；染色单软删行默认排除
- [x] 每节 LEFT JOIN 挂载反馈缸并聚合：状态分组、缸数量合计、未决问题计数（反馈记录表本票已建，问题计数可先返回 0 或真实计数——记录写入在 05，读逻辑本票就位）

- [x] 派生字段后端计算：延期标记（染色单交货日期 < 今天 且缸非 COMPLETED）、排产覆盖率（Σ缸数量÷颜色行数量，零/空分母按 0%）、超排标记（Σ缸数量>颜色行数量，红色）

- [x] 前端缸卡墙页（统计条+筛选栏+颜色行节列表+只读缸卡），Vue3 + Element Plus + scoped SCSS，卡片 grid auto-fill；DictTag 渲染状态
