# 09: 收付款前端（付款申请 Tab + 付款登记 Tab 单页两 Tab）

**What to build:** 在"财务 → 收付款"一个页面两个 Tab 完成付款全流程。Tab1 付款申请：看全部申请及申请额、已核销额、审批状态，按状态发起/编辑/提交/撤回/删除；发起时按类型分叉——对账付款选一张已确认对账单并看到确认额/已申请/可申请上限，预付付款填用途金额并参考该供应商实时预付余额。Tab2 付款登记：列出已审批未核销完的申请，出纳在一个弹窗里多选申请、按顺序分配金额、选资金账户、填实付与预付抵扣（带余额提示），一次登记完成；下方是不可修改的付款单流水。

**Blocked by:** 05（付款申请接口与审批状态）、06（付款登记接口与聚合）
