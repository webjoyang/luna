# ADR-0026：纱线规格经通用入库单进入库存——明细/流水扩展 itemType

**状态**：Accepted
**日期**：2026-09-25
**关联**：生产管理-织造执行、库存管理；ADR-0017（通用库存流水）、ADR-0027（领纱发纱）

## 背景

领纱发纱的前提是纱线有库存。新项目现状：

- 通用入库单明细**必须关联产品档案**，库存流水携带 `product_id`；
- 纱线规格（`yarnspec`，挂在纱线材质下）**不是产品**——产品档案字段为布匹设计（成分/克重/门幅）；
- 纱线采购单（`YarnOrder`）已存在，但此前规划的纱线专用台账已于 2026-09-21 撤销。

要让纱线进库存，三条路：

- (a) 扩展通用入库单：明细加物品类型，流水同步扩展；
- (b) 纱线采购单加"到货入库"动作，另写纱线库存流水，不走通用入库单；
- (c) 把纱线规格注册为产品档案，完全复用现成链路。

## 决策

采用 (a)：

1. **入库明细增加** `item_type`（`PRODUCT` 缺省 / `YARN_SPEC`）+ `yarn_spec_id` + `yarn_spec_name`（快照）。
   - PRODUCT 行：沿用产品选择，纱线字段禁填；
   - YARN_SPEC 行：选择纱线规格（材质→规格级联），产品字段禁填，单位固定 KG。
2. **库存流水同步扩展** `yarn_spec_id`，与 `product_id` **互斥**；一条明细/流水只表达一种物品。
3. **库存余额聚合键扩展**：`GROUP BY 物品（product_id 或 yarn_spec_id）+ 单位 + 仓库`；
   库存查询（余额列表、流水分页）产品与纱线共用，以物品类型列区分。
4. 审核/红冲、库位分配、放置过账机制完全复用，入库单状态机（ADR-0016）不变。
5. 纱线采购入库：手工开通用入库单（`type=PURCHASE`、明细 itemType=YARN_SPEC），
   不做"采购单一键到货"（本期保持入库单是唯一入库凭证）。

## 方案取舍

- (b) 被否：同一仓库出现两种入库凭证与两套库存账，库存查询、库位、盘点都要双路合并，长期成本高。
- (c) 被否：纱线进产品档案会污染产品域语义与所有按产品的业务列表/统计；纱线规格生命周期挂在材质下，与产品不同。
- (a) 的代价：改动已建成的入库单聚合保存、流水写入与余额查询；通过"新列可空、itemType 缺省 PRODUCT"保证存量单据与接口的向后兼容。

## 后果

- 库存域从"产品库存"加宽为"物品库存"；未来新物品类别（如辅料）可沿用同一模式，扩展时再加类型。
- 所有库存报表需显式处理物品类型列，不能假定每行都有产品。
- 纱线采购单与入库单之间本期无自动联动；采购到货进度靠人工开单，与布匹采购入库口径一致。
